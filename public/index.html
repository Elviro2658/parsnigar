    زبان فارسی ابزار آزاد کم دارد

    بیشتر ابزارهای پردازش متن، برای فارسی ساخته نشده‌اند؛ نتیجه‌اش داده‌های ناهمگون است: نویسه‌های عربی، اعراب، فاصله‌های نادرست و نیم‌فاصله‌های جاافتاده. این ناهم‌گونی، کیفیت هر کاری که با متن فارسی انجام می‌شود را پایین می‌آورد.

    نرمال‌سازی، اولین قدم هر کاری است

    جست‌وجو، ترجمه ماشینی، گفتار‌به‌متن، مدل‌های زبانی، تحلیل داده و حتی مرتب‌سازی ساده، همه به متنی یکدست نیاز دارند. یک کتابخانه کوچک و آزاد، می‌تواند پایه‌ی ده‌ها پروژه دیگر شود.

    شفافیت و مالکیت کاربر

    همه محاسبات در مرورگر انجام می‌شود؛ متن کاربر به هیچ سروری فرستاده نمی‌شود. کد هم آزاد است تا هر کس آن را بخواند، اصلاح کند و در پروژه خودش به کار ببرد.

    نقشه راه

    آنچه در نسخه‌های بعدی به جعبه‌ابزار اضافه می‌شود.

    1. نسخه ۱.۰ (اکنون): نرمال‌سازی پایه، ارقام، نشانه‌گذاری، نیم‌فاصله، آمار متن و نمایش تفاوت.
    2. نسخه ۱.۱: حالت خط‌فرمان و آزمایش‌های خودکار برای قواعد نرمال‌سازی.
    3. نسخه ۱.۲: پشتیبانی از نویسه‌های نادر و شکل‌های عربی اضافه، املا و شکل‌های شبه‌عربی.
    4. نسخه ۱.۳: مقایسه دو متن فارسی، یافتن واژه‌های نادرست و پیشنهاد اصلاح.
    5. نسخه ۲.۰: بسته‌های زبان‌های ایرانی (کردی، بلوچی، پشتو، آذری) بر پایه همین قواعد.

    About this project (English)

    A short summary for international reviewers, researchers and collaborators.

    The problem

    Persian is usually called a low-resource language, but the more precise problem is that it is normalization-poor: the same word is written several different ways depending on keyboard, operating system and writer — Arabic letter forms (ي, ك), optional diacritics, kashida, half-space (ZWNJ) errors and mixed digit sets. Computers treat those variants as different strings, which breaks search, deduplication, machine translation and language models.

    The toolkit

    ParsNegar is a dependency-free, MIT-licensed JavaScript library with a browser interface and a command line tool. Everything runs locally: no text is uploaded to any server, and the web app works offline. The rules are explicit, readable and individually switchable, so users can see exactly what changed.

    Who benefits

    Persian-speaking developers, students, researchers, journalists and data teams, plus any downstream Persian NLP or AI project that needs clean input. The same rule engine is designed to extend to other Iranian languages that are even less served by existing tooling.

    License: MIT. Library: /persian-text.js. Tests: node tests/normalize.test.mjs. Command line: parsnigar note.txt --preset nlp.
